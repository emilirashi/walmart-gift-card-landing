# Walmart $500 Gift Card Landing Page

A modern, responsive landing page for a limited-time Walmart $500 gift card offer.

## Features

- ✨ Clean, professional design
- 📱 Fully responsive for all devices
- 🎯 Clear call-to-action button
- ❓ Interactive FAQ section
- 🎨 Walmart brand colors
- ⚡ Fast loading with inline CSS

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Or deploy to any web hosting service (GitHub Pages, Netlify, Vercel, etc.)

## Customization

You can easily customize:
- Gift card amount (currently $500)
- Brand colors (change the `#0071ce` color code)
- CTA link (update the href in the button)
- FAQ questions and answers
- Text content

## GitHub Pages Deployment

To deploy this landing page to GitHub Pages:
1. Go to repository settings
2. Scroll to "GitHub Pages"
3. Select `main` branch as source
4. Your site will be available at `https://emilirashi.github.io/walmart-gift-card-landing/`
